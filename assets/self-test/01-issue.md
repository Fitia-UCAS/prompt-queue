# 问题说明

## 现象

一个任务第一次执行失败，重试成功后又执行了一次。同一批任务只入队一次，没有定时器，也没有外部进程重复提交。

## 环境与输入

Node.js 22，单进程。队列的 maxAttempts 设为 2，包含第一次执行。

按顺序加入 job-A 和 job-B。job-A 第一次抛出 code 为 E_TEMP 的错误，之后成功；job-B 始终成功。

## 复现

在附件所在目录运行：

~~~sh
node 04-task-queue.test.cjs
~~~

第一项断言失败。记录到的执行顺序为：

~~~text
job-A#1
job-B#1
job-A#2
job-A#2
~~~

预期只有前三行。第二次 job-A#2 是多出来的执行，不是重复打印日志：记录是在任务函数入口追加的。

## 调试边界

先检查队列如何处理失败和重新入队，再核对重试条件。不要通过隐藏日志、按任务编号去重输出或禁用重试来让测试通过。

后面会提供队列实现、重试策略、测试，以及一份候选修复。所有文件都属于这个问题。

修复后，job-A 应执行两次，job-B 应执行一次。
